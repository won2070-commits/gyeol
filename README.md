# 결 — 나를 알아가는 시간

한국어 성격 탐색 웹앱. PC와 모바일 브라우저에서 작동하며 별도 라이브러리나 서버 계정이 필요 없습니다.

## 실행

Node.js 20 이상에서:

```sh
cd /Users/dowonuk/Desktop/Cowork/성향검사
npm start
```

http://localhost:5221 에 접속합니다. 종료는 터미널에서 Ctrl+C. 테스트는 `npm test`.

외부 호스팅에서는 `docs/` 폴더를 정적 배포하면 됩니다. 현재는 로컬 실행 버전이며 인터넷 공개 배포나 앱스토어 등록은 하지 않았습니다. 저장소는 접속 주소별로 분리되므로 localhost와 127.0.0.1은 다른 기록을 가집니다.

## 구현한 기능

- 직접 작성한 한국어 상황 질문 32개, 양방향 균형 문항
- 성향이 비슷한 축만 최대 8개 추가 질문
- 자동 저장, 진행 단계 복원, 이전 답 수정, 미응답 안내
- 네 성향의 연속 점수, 완전 중립 X 표시, 경계 구간 설명
- 응답 패턴 점검 안내 (정확도 판정 아님)
- 16유형별 해설: 요약, 자주 나타나는 모습 3, 시도해 볼 것 2, 편한 환경
- 결과에 대한 자기 확인과 메모
- 최근 20회 기록, 최근 두 번의 비교, JSON 내보내기
- 확인 대화상자를 거치는 전체 삭제
- 320px 이상 반응형, 네이티브 라디오 및 키보드 사용, 초점 표시
- 외부 요청, 분석 추적, 로그인, 외부 AI 사용 없음

## 파일

- `docs/data.js`: 문항과 채점, 추가 질문 결정, 임시 응답 점검
- `docs/app.js`: 화면, 라우팅, 브라우저 저장, 내보내기
- `docs/style.css`: 반응형 화면
- `server.mjs`: 로컬 정적 서버
- `tests/scoring.test.mjs`: 채점·복원·유형 해설 검증 13개
- `RESEARCH.md`: 비교 근거, 제품 결정, 후속 타당화 계획
- `QA.md`: 실행한 검사와 확인하지 못한 범위

## 정확도에 관한 범위

공식 MBTI® 검사가 아닙니다. 문항은 다른 서비스에서 복사하지 않은 독자 초안이며 심리측정 연구로 검증되지 않았습니다. 추가 질문과 역방향 문항은 설계 선택이지 정확도의 증거가 아닙니다. 선호 점수는 확률/신뢰도/정확도가 아닙니다. 실제 사용자 대상 연구는 수행하지 않았습니다.

보관 데이터는 브라우저 localStorage에 평문 저장됩니다. 같은 브라우저 사용자는 볼 수 있습니다. 공용 기기에서는 사용 후 삭제하세요. 브라우저 데이터가 지워지면 복구되지 않습니다. JSON 내보내기는 보관용이며 가져오기는 구현하지 않았습니다.
